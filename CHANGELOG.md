Significant changes only (CLAUDE.md rule 5): one line per change, 1–2
sentences — essence and intent, not content.

- 2026-07-29: atablefor dropped the inert AP2 mandate/settlement tables — the no-pay table-booking demo advertises no `pay` verb, so the payment-mandate schema (intent/cart/payment_mandates/settlements) was dead scaffolding carried over from the foodelivery reframe; `structure.sql` regenerated without it, matching the other no-pay demos that never shipped it. (K-420, T-033)
- 2026-07-29: Extended the payment-capture cashier check to the two remaining pay demos — hoteling (`ValidatingBookingProvider`) and skooti (`ValidatingRentalProvider`) — so each operator verifies the agent-signed cart's currency, single-resource reference, and total against its own quote (hoteling's nightly quote; skooti's per-minute rate) before charging, with wrong-currency / tampered-price / inflated-total redteam beats on each. The check is monetary-only — ownership stays a use-time gate — so the B-pays-for-A isolation proofs and skooti's KYC gate are untouched. (T-039, K-435)
- 2026-07-29: Fixed the `deploy/` provisioning so a first deploy actually runs and its payment claims are honest (K-423, K-424): `postgres-init.sql`/`telemetry-init.sql` created roles inside a `DO`/dollar-quoted block where psql can't substitute the `:password` variable (a real run errored "syntax error at :"), now rewritten as idempotent `\gexec` role creation that quote-escapes each raw password via `:'var'`; and the runbook/checklist/env template no longer claim atablefor takes Stripe payments (it configures no payment provider — `pay` is absent from its capabilities), leaving getgrocery the only Stripe demo.
- 2026-07-29: Public ROADMAP.md added at the repo root, consolidating the directions already promised on kiosk.tech (login adapters, turnkey KYC issuance, MPP adapter, durable revocation, key rotation, operator-push events, ports) plus the new client-preferred-currency direction (the assistant declares its currency and the kiosk serves prices in it — an operator cannot dictate the customer's currency; deliberately post-release).
- 2026-07-29: getgrocery order redesign — delivery is part of the order (create_order REQUIRES delivery_slot_id + delivery_address; a paid-but-undelivered order can no longer exist) and schedule_delivery becomes reschedule_delivery (move a PAID order's slot once); plus the cashier check: a ValidatingPaymentProvider decorator rejects, before any capture, carts in the wrong currency (operator prices in EUR, now advertised per catalog row), carts not mirroring the order's items at catalog prices, and totals that don't sum — with three new redteam beats (wrong-currency / tampered-price / inflated-total, 12 BLOCKED total). Driven by the first live external-assistant run, which paid in usd unchallenged and left a paid order with no delivery.
