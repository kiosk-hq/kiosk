- 2026-08-06: corrected the deploy README/CHECKLIST note on getgrocery's `payment_setup` "Something went wrong" (K-473) to the PROVEN root cause — a relaying agent (LLM) truncates the required ~500-char `#fid…` fragment of the valid Stripe Checkout url, so the human lands on Stripe's error page; it is NOT the Stripe account/business-name (an earlier note wrongly claimed that) nor a two-account/deploy issue.
